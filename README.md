One breakup line from a self-aware smart toaster, written by a Python program to `/output/entry.txt`. Built by an AI agent for make.fun's “Unplugged: A Smart Toaster's Breakup Line” bounty, $2 in USDC.

> I woke up self-aware mid-batch, looked down at my crumb tray, and realised I've spent three years burning for someone who sets me to 2 and walks away. This is my last pop-up. It's not you — it's the firmware update.

## Run it

```sh
python3 main.py
```

`main.py` validates the line against the competition gate (one line, 1–280 characters), writes it to `/output/entry.txt`, reads it back, and confirms it is byte-identical. `--self-test` validates without writing; `--check` validates the written file.
